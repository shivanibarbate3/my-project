# Shivani CMS - Client (Scaffold)

This is a minimal Vite + React scaffold placed in `client/`.

Recommended quick commands (run from backend root):

```bash
# install client deps
npm run install-client

# run client dev server (proxied to backend /api)
npm run client

# build client
npm run build-client

# start backend (serves client in production)
npm start
```

The backend is configured to serve `client/dist` when `NODE_ENV=production`.
